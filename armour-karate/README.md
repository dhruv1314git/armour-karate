# Armour Karate Academy Management System

## Project Overview

Armour Karate Academy Management System is a web-based application developed to support the management of a martial arts academy.

The project includes public academy pages, student account functionality, and administrator management interfaces.

## Technologies Used

- HTML5, CSS3, JavaScript
- Bootstrap 5
- PHP 8.2+
- MySQL / MariaDB

## Main Features

- Student registration and login
- Student profiles and dashboards
- Karate belt information
- Fee and examination information
- Academy events and gallery
- Academy locations and contact pages
- Administrator dashboard
- Student and academy content management
- Session-based authentication and CSRF protection

## Repository Information

This repository contains selected application source code, database migrations, and supporting assets.

Private student information, uploaded documents, database credentials, and production configuration are intentionally excluded.

The repository is intended to demonstrate the project's design and implementation, rather than serve as a complete standalone deployment.
